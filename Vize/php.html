PHP Sınav Hızlı Tekrar & Kod Çıktısı Rehberi

Değişkenler ne işe yarar, operatörler, döngüler ve hazır fonksiyonların çıktıları

1. Değişkenler & Değişken Değişkenler ($$a)

Ne işe yarar? Verileri (sayı, metin, dizi) bellekte geçici olarak saklamaya ve program içinde tekrar kullanmaya yarar. $ ile başlar, rakamla başlayamaz.

$a = "renk";
$$a = "Mavi"; // $renk = "Mavi" olur
echo $renk;   // Çıktı: Mavi

$x = 5; $y = &$x; // Referans atama
$y = 20; echo $x; // Çıktı: 20

2. Mod Alma (%) ve Bölme (/) Çıktısı

/ (Bölme): Tam bölünmezse ondalıklı (float) sonuç verir. intdiv(a,b) sadece tam kısmı verir.
% (Mod): Bölümden kalanı verir (Çift/tek sayı kontrolünde kullanılır).

echo 10 / 4;        // Çıktı: 2.5
echo 10 % 3;        // Çıktı: 1 (Kalan)
echo intdiv(10, 3); // Çıktı: 3 (Tam kısım)
echo 10 + 6 / 2;    // Çıktı: 13 (Önce bölme!)

3. Operatörler (. , == , === , ++ , ??)

. (Nokta): String birleştirir. + sayısal toplar.
== sadece değere bakar, === hem değer hem veri tipine bakar.

$a = "5"; $b = 10;
echo $a + $b; // Çıktı: 15
echo $a . $b; // Çıktı: 510
$x = 5;
echo $x++;    // Ekrana 5 yazar, x=6 olur
echo ++$x;    // x=7 olur, ekrana 7 yazar

4. If & Switch-Case Kodu (Çıktı Tuzağı)

Switch-case'de break; unutulursa eşleşen case'den sonraki case'ler de break görene kadar koşulsuz çalışır (Fall-through)!

$gun = 2;
switch($gun) {
  case 1: echo "A"; break;
  case 2: echo "B"; // break YOK!
  case 3: echo "C"; break;
  default: echo "D";
} // Çıktı: BC

5. Foreach ve do-while Döngüleri

foreach: Dizileri gezer. do-while: Koşul sonda kontrol edildiği için koşul false olsa bile en az 1 kez çalışır!

$x = 10;
do {
  echo $x; // Koşul yanlış ama 1 kez çalışır!
} while ($x < 5); // Çıktı: 10

$d = ["a"=>1, "b"=>2];
foreach($d as $k=>$v) echo "$k:$v "; // a:1 b:2

6. Fonksiyonlar (Çıktı) & Diziler

Fonksiyonlarda varsayılan parametre verilebilir. return sonucu döndürür ve fonksiyonu o satırda bitirir. Dizilerde indeks 0'dan başlar.

function hesap($a, $b = 3) {
  return $a * $b;
}
echo hesap(4);    // Çıktı: 12 ($b=3 alır)
echo hesap(4, 5); // Çıktı: 20 ($b=5 olur)

7. strtotime() Ne İşe Yarar & Çıktısı

İngilizce metin halindeki tarihi veya zaman ifadelerini ("+1 day", "+2 weeks", "2026-05-10") Unix Timestamp (saniye) değerine çevirir.

$t = strtotime("2026-05-10 +5 days");
echo date("d.m.Y", $t);
// Çıktı: 15.05.2026

8. str_repeat() & Hazır Fonksiyonlar

str_repeat(metin, tekrar_sayisi): Verilen metni belirtilen sayı kadar yan yana tekrarlar. (0 verilirse boş string döner).

echo str_repeat("PHP-", 3);
// Çıktı: PHP-PHP-PHP-

echo strlen("Kütahya"); // Harf/Byte sayısı
echo substr("Merhaba", 0, 3); // Çıktı: Mer

9. var_dump() Ne İşe Yarar & Çıktısı

Bir değişkenin veya ifadenin veri tipini, uzunluğunu ve değerini detaylıca ekrana basar. Hata ayıklamada (debug) kullanılır.

var_dump(25);       // int(25)
var_dump("PHP");    // string(3) "PHP"
var_dump(5 == "5"); // bool(true)
var_dump(5 ==="5"); // bool(false)
